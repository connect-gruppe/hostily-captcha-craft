# hostily Captcha

Privacy-friendly spam protection without cookies. Site key, secret, service URL, mode, language and the behavior when the service is
unreachable are set in **Settings → Plugins → hostily Captcha**. Without site key and secret nothing is protected and nothing is blocked.

Datenschutzfreundlicher Spamschutz ohne Cookies. Site-Key, Secret, Dienst-URL, Modus, Sprache und das Verhalten bei Ausfall des Dienstes
stehen unter **Einstellungen → Plugins → hostily Captcha**. Ohne Site-Key und Secret ist nichts geschützt und nichts gesperrt.
